## 紙張與摺法

| 項目 | 規格 |
|---|---|
| 紙張 | A4（210 × 297），雙面，白底 |
| 列印 | 雙面、長邊翻頁 |
| 摺法 | Z 字三折（風琴摺）：token 面朝上，上三分之一往前摺、下三分之一往後摺 |
| 每格 | 99（297 ÷ 3） |
| 摺好 | 210 × 99 |
| 摺線記號 | token 面左右邊緣，在 99、198 處各一段淺灰刻線（長 4） |

摺好後露在外面的兩面：背面上格（封面）、token 面下格。

## token 面

| 項目 | 規格 |
|---|---|
| 字 | 思源宋體（Noto Serif CJK TC），8pt |
| ID | 思源等寬（Noto Sans Mono CJK TC），約 4.2pt，灰色，寫在字的下方 |
| 分隔 | 每個 token 左側一條細灰線 |
| 位元組碎片 | 灰底十六進位，例如 `‹E8 A3›` |
| 空格 | 顯示為 `·` |
| 換行 | 不畫符號，只留空格子和它的 ID；段落照樣換行 |
| 對齊 | 每行靠左，整塊在格子裡上下左右置中 |
| 每格留白 | 左右 15，上下至少 4（排版腳本會檢查） |
| 多出來的換行 | 段落之間單獨的換行 token 接在上一行行尾，不另起一行 |
| 不印 | 檔案開頭的 Markdown 標題那一行（`# README：…`） |
