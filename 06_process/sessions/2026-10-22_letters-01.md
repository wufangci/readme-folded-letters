# 2026-10-22　信的裝置 第一輪

## 做了什麼

- 討論信的裝置：怎麼切片段、封或不封、寄件人、消耗與擺法。
- 決定把信印成 token 的樣子，四個片段、四種樣式，A4。
- 排第一封的樣張，改了 9 版：
  - **v01–v06**：單張樣張 → 資訊移到背面 → 拿掉標題行 → 8pt 置中靠左 → 換行只留 ID → 封面改成 `#README` 的 token 和 QR code。
  - **v07–v08**：三種摺法：信紙三折、Z 字三折、對開門摺，各附摺法示意圖。
  - **v09**：Z 字三折整理版：封面只留 `#README` 和角落的 QR code，信切成三塊各落一格。
- 整理成這個 repo：依 `readme-token-animation`、`readme-exhibition`、`readme-video` 的結構分資料夾；排版腳本可以從 `LETTER.md` 重新產生定稿。

- 依定版排完其餘的信：整封信分成六封（第 0–4 段各一封，第 5、6 段合成第六封），第二到第六封暫定。

## 作者的關鍵回饋

- 「假設信拆成四個篇幅，這樣就是等於信有四種樣式的意思」
- 「標題拿掉、地址拿掉 收件人拿掉，這些資訊要印在另一面」
- 「文字還是靠左對齊好了」
- 「符號拿掉、只留 ID」（換行）
- 「封面親愛的人工智慧改成 #README 拆成 token 的樣子」
- 「主要是Ｂ的排版我覺得看起來有點擁擠」
- 「QR code 可以小一點然後放角落嗎」
- 「文章乾脆就切三段平均拆在每個摺痕裡不是比較好嗎」
- 「先這版定下來」
- 「六封，最後一段併入第六封」「照原文順序，露出什麼算什麼」
- 「先暫定推上repo」
