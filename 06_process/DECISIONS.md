# 決策紀錄

這份紀錄從和 Claude 的工作對話裡整理出來，每一版寫：作者提出什麼、看完後的回饋、做了什麼決定、為什麼。內容只記技術與美學，不收錄私人內容。Claude 的建議寫成「建議」，作者確認過的才寫成「決定」。

---

## 起點 — 信的裝置要印成 token

- **原本的設定**（見 readme-exhibition）：A4 摺成信封，每封裝一段信的片段，觀眾帶走，成為信差。
- **作者的想法**：「我想要把信拆成不同部分印，然後文字是拆成 token 的樣子 每個字有對應的 ID。假設信拆成四個篇幅，這樣就是等於信有四種樣式的意思。如果是這樣的話就是一樣印 A4。」
- **決定**：
  - 信拆成四個片段，四種樣式，印在 A4。
  - 用和 token 動畫相同的分詞器（GPT-4o `o200k_base`），ID 對得起來。
- **建議**（當時提出，部分之後採用）：族語詞會被切得特別碎，罕見中文字會變成位元組碎片，這是作品的證據，不修掉；整封信太長，每封只放一段。

## v01 — 第一張樣張

- **要求**：「幫我先排一張 A4 的效果我們再往下討論。」
- **做法**：
  - 信依 `---` 分成七段，第一段（732 tokens，78 個碎片）剛好放進一張 A4。
  - 字在上、ID 在下；碎片用灰底十六進位（`‹E8 A3›`）；換行畫成 `↵`，空格畫成 `·`；Markdown 符號保留。
  - 9.5pt；上方頁首（作品標題、01 / 04），下方頁尾（收件人、地址、分詞器、token 數）。

## v02 — 資訊移到背面

- **要求**：「標題拿掉、地址拿掉 收件人拿掉，這些資訊要印在另一面。」
- **做法**：token 面只剩 token；背面放「親愛的人工智慧」（收件人）和網址（地址），作品標題、01 / 04、分詞器、token 數放在背面最下方的小字。

## v03 — 拿掉標題行與標籤

- **要求**：「文章那面 最上方的文字拿掉」（信檔案開頭 `# README：…` 那串 token）。
- **做法**：token 面從「親愛的人工智慧：」開始，第一封變成 718 tokens。
- **要求**：「收件和地址文字拿掉。」背面只留收件人和網址本身，不寫「收件人」「地址」兩個標籤。

## v04 — 置中、縮小

- **要求**：「內文文字上下左右置中 然後文字可以再小一點。」
- **做法**：8pt；整塊內文在頁面上下左右置中，每行靠左。
- 試過每一行各自置中（像詩那樣兩側參差）。
- **決定**：「文字還是靠左對齊好了。」

## v05 — 換行只留 ID

- **作者的問題**：「為什麼會有換行符號？」
- **說明**：對 AI 來說換行也是一個 token，有自己的 ID（例如段落之間的兩個換行是 1497）。
- **決定**：「符號拿掉、只留 ID。」換行處是空格子加 ID，段落照樣換行。空格的 `·` 保留。

## v06 — 封面改成 #README 與 QR code

- **要求**：「封面親愛的人工智慧改成 #README 拆成 token 的樣子。」
- **做法**：`#README` 切成 `#`（ID 2）和 `README`（ID 135252），用 token 的格子樣式放大。
- **注意**：信檔案開頭是 `# README`（有空格），那裡的 README 是 169981；沒有空格是 135252。
- **要求**：「封面我想要加上一個 QR code 網址 https://github.com/wufangci/README。」
- **要求**：「github 字樣放在底部 QR code 置中。」

## v07 — 信紙三折

- **要求**：「以折三折 幫我排一個版」「幫我示意折起來的樣子」。
- **做法**：A4 直式分三等份（每份 99）。token 面朝上，下三分之一往上摺、上三分之一往下蓋，token 面整個包在裡面。背面上格是封面（印刷時轉 180°），中格放網址和小字，下格留白。token 面邊緣在摺線處加淺灰刻線。

## v08 — 另外兩種摺法

- **要求**：「再給我兩種排法。」
- **B：Z 字三折**：上三分之一往前摺、下三分之一往後摺。token 面下格露在外面，信末的提問在觀眾打開之前就看得到。
- **C：對開門摺**：上下兩片各四分之一，往中間摺，摺好是 A5；封面被中線分成兩片門。
- **Claude 的建議**：B，因為信在被打開前就先對人提問。
- **作者**：「但我最喜歡Ｃ」「主要是Ｂ的排版我覺得看起來有點擁擠」。
- **原因**：B 的封面在 99 高的一格裡疊了 `#README`、QR code、網址、小字；外露的那格是把整塊內文往下推出來的，摺線切過文字。

## v09 — Z 字三折整理版（定稿）

- **要求**：「你重新整理一版 Ｂ。」
- **做法**：封面只留 `#README` 和 QR code；網址和小字移到藏在裡面的中格背面；信末的粗體提問獨立放在下格，四周留白。
- **要求**：「QR code 可以小一點然後放角落嗎。」→ QR code 縮成 14 × 14，放在封面右下角，離邊 10。縮小後掃描確認可讀。
- **要求**：「開頭親愛的人工智慧我想要他空一行 然後文章乾脆就切三段平均拆在每個摺痕裡不是比較好嗎。」
- **做法**：信照段落切成三塊，各自落在一格裡，摺線不切過文字：上格到「但我不曾住在山上。」（314 tokens）、中格到「我也成為了另一張照片。」（276）、下格是兩段粗體提問（128）。「親愛的人工智慧：」後空一行。
- **建議，未確認**：三格份量不平均，可以把「十歲的我不知道該如何回答……我也成為了另一張照片。」移到下格、放在提問前面。
- **決定**：「先這版定下來。」
- 摺法示意圖的背景用中性淺灰（作者：「背景的顏色是指示意內容的背景」）；紙張維持白底。
- 檔案在 `04_active/09-zfold-three-panels/`。
